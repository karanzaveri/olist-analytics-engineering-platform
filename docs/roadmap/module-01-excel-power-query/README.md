# Module 1 · Advanced Excel and Power Query

Build a repeatable delivered-sales report for an Olist marketplace analyst. Allow 60–90 minutes. Use Excel for Windows and the four bundled CSVs.

1. Open [the practical assignment](learner/ASSIGNMENT.md).
2. Use [the data dictionary](learner/DATA.md) when choosing keys and column types.
3. Keep [the instructor solution](instructor/SOLUTION.md) closed until you have attempted the lab. The instructor folder also contains the expected report by month and state.

Create your own workbook from a blank file. Keep your workbook beside the exercise folder or in another folder you can write to. All inputs are local.
