# Module 3 · Data Analyst Interview & Portfolio Readiness

Practice explaining, debugging and defending the Olist portfolio under interview conditions. Module 1 covers the Excel build. Module 2 covers applied statistical computation. This module uses those foundations to practice live reasoning, evidence review and stakeholder communication.

| Material | Use |
|---|---|
| [Technical interviews](TECHNICAL_INTERVIEWS.md) | Ten topics, three difficulty levels, one practical drill per topic |
| [Business cases](BUSINESS_CASES.md) | Seven timed cases and a scoring rubric |
| [Portfolio audit](PORTFOLIO_AUDIT.md) | Evidence gaps and priorities before sharing |
| [Skills evidence matrix](SKILLS_EVIDENCE_MATRIX.md) | Artifacts, confidence, talking points and learning gaps |
| [Reference solutions](instructor/REFERENCE_SOLUTIONS.md) | Answer keys, checks and business case scoring anchors |

1. **Evidence tour, 45 minutes.** Open one artifact for each strong skill. Prepare a 60-second project introduction and identify which claims depend on local changes.
2. **Technical practice, two sessions of 75 minutes.** Start with SQL, Python, dbt, and data quality. Then do orchestration, product analytics, reporting, inference, retention and forecasting. Answer aloud before checking the solutions.
3. **Case practice, two sessions of 60 minutes.** Run three cases per session at 15–20 minutes each. Use the stakeholder case as a final mock with another person if available.
4. **Portfolio rehearsal, 60 minutes.** Show a clean local reproduction, a dashboard walkthrough and one failure you can diagnose. Score yourself with the rubric and repeat your lowest-scoring drill.

Remaining roadmap gaps include repeated timed SQL and Pandas work on unfamiliar inputs, independent practice with semantic model and report debugging, an audience-tested stakeholder walkthrough, and a reproducible clean-checkout demonstration. Production operation and personal proficiency need separate evidence. See the audit for the priority order.
